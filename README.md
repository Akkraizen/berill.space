# berill.space

The landing page of [Berill](https://github.com/Akkraizen/Berill), a local-first personal workspace
for Windows and Android. Built with Vue 3, TypeScript, and Vite as a static site.

## Development

Requires Node.js 20.19+ or 22.12+ (the minimum for Vite).

```sh
npm install
npm run dev
```

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server with hot reload. |
| `npm run build` | Type-check with `vue-tsc` and build the site into `dist/`. |
| `npm run preview` | Serve the built `dist/` locally. |
